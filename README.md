# CodeFy

Agente que trabalha nos seus arquivos: você conversa com ele e ele lê, cria e edita arquivos, roda comandos e usa o navegador.

## Baixar

Pegue a versão mais nova em **[Releases](https://github.com/lucasahimself21/codefy-instalador/releases/latest)**:

| Sistema | Arquivo |
|---|---|
| Windows | `CodeFy-Setup-<versão>.exe` |
| Mac (M1, M2, M3, M4) | `CodeFy-<versão>-arm64.dmg` |
| Mac (Intel) | `CodeFy-<versão>-x64.dmg` |

**Mac:** abra o `.dmg` e arraste o CodeFy pra Aplicativos. Na primeira vez, se o Mac bloquear, clique com o botão direito no app › Abrir.

## Primeiro uso

1. Abra o CodeFy e escolha a pasta de projetos (isolado no Docker, recomendado, ou direto no computador).
2. Cole o **token** que o admin mandou em Configurações › Token.

O app se atualiza sozinho ao abrir.
